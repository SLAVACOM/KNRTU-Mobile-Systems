# My City («Моя Казань») — эскизы и план

## 4. Эскизы экранов

**Compact** (телефон) — три экрана, переходы через Jetpack Navigation:
```
┌───────────────┐   ┌───────────────┐   ┌───────────────┐
│ Моя Казань    │   │ ← Музеи       │   │ ← Нац. музей  │
├───────────────┤   ├───────────────┤   ├───────────────┤
│ 🏛 Достоприм. │ → │ ▣ Нац. музей  │ → │   [иконка]    │
│ 🖼 Музеи      │   │ ▣ Эрмитаж     │   │ 📍 Кремлёвская│
│ 🌳 Парки      │   │ ▣ ...         │   │ Описание...   │
│ 🎭 Театры     │   │               │   │               │
│ 🍴 Кухня      │   │               │   │               │
└───────────────┘   └───────────────┘   └───────────────┘
```
**Medium** (раскладушка, планшет в портрете) — категории в `NavigationRail`, список мест → детали:
```
┌──┬──────────────────┐
│🏛│ Музеи             │
│🖼│ ▣ Нац. музей      │  → детали на весь экран (← назад)
│🌳│ ▣ Эрмитаж         │
│🎭│ ...               │
└──┴──────────────────┘
```
**Expanded** (планшет, десктоп) — постоянное боковое меню + список + детали (canonical list-detail):
```
┌────────────┬──────────────┬─────────────────────┐
│ Моя Казань │ ▣ Нац. музей │  [иконка]           │
│ 🏛 Достоп. │ ▣ Эрмитаж ◀  │  Центр «Эрмитаж»    │
│ 🖼 Музеи ◀ │ ▣ ...        │  📍 Казанский Кремль│
│ 🌳 Парки   │              │  Описание...        │
└────────────┴──────────────┴─────────────────────┘
```

## 5. План
1. Слой данных: `Category`, `Place`, `LocalPlacesDataProvider` (5 категорий × 4 места, строки в `strings_city.xml`).
2. `MyCityViewModel` + `MyCityUiState` (`StateFlow`, UDF): текущая категория и место.
3. Экраны: `CategoriesScreen`, `PlacesScreen`, `PlaceDetailsScreen`, тема `MyCityTheme`.
4. Навигация: `NavHost` с маршрутами `Categories → Places → Details`, `TopAppBar` с заголовком и кнопкой «Назад».
5. Адаптивность: `WindowWidthSizeClass` → `NavigationRail` (Medium) / `PermanentNavigationDrawer` +
   list-detail (Expanded); «Назад» на Expanded закрывает приложение.
6. Тесты навигации и адаптивных раскладок, проверка на эмуляторе с разными размерами окна.
